# Getting help

SEO Control Center is free, community-supported software.

- **Using SEOcc:** start with the [user guide](docs/guide/README.md) and its [troubleshooting chapter](docs/guide/11-troubleshooting.md).
- **Questions and ideas:** [GitHub Discussions](https://github.com/seoccnet/seo-control-center/discussions).
- **Bugs:** [GitHub Issues](https://github.com/seoccnet/seo-control-center/issues). Attach the support bundle from *System health* if you can. It leaves out passwords and keys, but read it before you post.
- **Security problems:** report them privately, as described in [SECURITY.md](SECURITY.md).
- **Project website:** [seocc.net](https://seocc.net/).

Google, DataForSEO, OpenAI and Anthropic support their own services. Your host can help with PHP versions, cron jobs and certificates.
