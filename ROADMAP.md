# Roadmap

SEO Control Center is in early alpha. Finished work is in [CHANGELOG.md](CHANGELOG.md).

## Now

- A first public release: installation from GitHub, clear documentation and a stable base for contributors.
- Fixing what people report from real websites and hosting setups.

## Next

- Checking for new releases from inside the app, without a vendor server.
- Support for more hosting setups, and clearer guidance where PHP 8.5 is not yet available.
- More search engines and AI assistants in visibility tracking.

## How to influence this

Open a [feature request](https://github.com/seoccnet/seo-control-center/issues/new/choose) or start a [discussion](https://github.com/seoccnet/seo-control-center/discussions). This list is a direction, not a promise.
